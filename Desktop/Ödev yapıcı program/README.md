# 🎓 Ödev Asistanı - AI Powered Education App

Modern, yapay zeka destekli eğitim asistanı mobil uygulaması.

## 📱 Özellikler

- 📸 Kamera ile soru tarama (OCR)
- 🤖 AI destekli adım adım çözüm
- ✍️ Kompozisyon ve essay yazma
- 🔢 Matematik problemleri çözme
- 🌍 Çeviri desteği
- 📚 Soru geçmişi

## 🛠️ Teknoloji Stack

### Frontend (Mobil)
- Flutter 3.x
- Provider (State Management)
- Google ML Kit (OCR)
- Camera Plugin
- Flutter Math (LaTeX rendering)

### Backend
- Node.js + Express
- PostgreSQL (NeonDB - Serverless)
- JWT Authentication
- OpenAI/Gemini API Integration

## 📁 Proje Yapısı

```
odev-asistani/
├── mobile/                 # Flutter uygulaması
├── backend/               # Node.js API (PostgreSQL)
└── README.md
```

## 🚀 Kurulum

### Mobil Uygulama
```bash
cd mobile
flutter pub get
flutter run
```

### Backend
```bash
cd backend
npm install
npm run dev
```
