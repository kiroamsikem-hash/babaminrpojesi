# ⚡ HEMEN BAŞLA!

## 🎯 3 Adımda Deploy

### 1️⃣ Login
```bash
vercel login
```
→ Tarayıcı açılacak, giriş yap, "Confirm" tıkla

### 2️⃣ Deploy
```bash
vercel --prod
```
→ Soruları cevapla (hepsine Enter bas)

### 3️⃣ Domain Ekle
```bash
vercel domains add hksg.qzz.io
```
→ DNS ayarlarını yap (DOMAIN_AYARLARI.md'ye bak)
